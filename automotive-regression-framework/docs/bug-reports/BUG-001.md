# Problem Report: BUG-001 — False-Positive Warning at Exact Maximum Permitted Speed

- **ID:** BUG-001
- **Title:** VehicleController triggers false-positive WARNING at exact maximum allowable speed boundary (130.0 km/h)
- **Status:** Verified / Closed
- **Severity:** High (Functional boundary defect causing erroneous false-positive warning alerts)
- **Affected version/commit:** `v0.1.0` (simulated boundary regression)
- **Fixed in version:** `v0.1.1`
- **Environment:** Windows 11 x64, Python 3.11.3 / 3.12, pytest 9.1.1, pytest-cov 7.1.0
- **Requirement/test ID:** REQ-001 / REG-001 (`test_regression_bug_001_exact_max_speed_is_normal`)

---

## 1. Summary
When `VehicleController.evaluate()` receives a `speed_kmh` value exactly equal to the configured upper limit (`max_speed_kmh = 130.0 km/h`) and normal engine operating temperature (e.g., 90.0 °C), the controller evaluates to `ControllerState.WARNING`. Per system specification REQ-001, upper thresholds are inclusive safe limits; a value equal to the limit must produce `ControllerState.NORMAL`.

---

## 2. Preconditions
- `VehicleController` instantiated with default `ControllerConfig` (`max_speed_kmh = 130.0`, `max_temperature_c = 110.0`).
- Valid engine temperature within safe operating range (e.g., 90.0 °C).

---

## 3. Steps to Reproduce
1. Initialize the controller:
   ```python
   controller = VehicleController()
   ```
2. Call `evaluate` with speed exactly at the upper safe threshold:
   ```python
   state = controller.evaluate(speed_kmh=130.0, temperature_c=90.0)
   ```
3. Observe returned `ControllerState`.

---

## 4. Expected Result
According to REQ-001, the upper limits are inclusive safe limits:
```python
state == ControllerState.NORMAL
```

---

## 5. Actual Result
The controller returned:
```python
state == ControllerState.WARNING
```

## 7. Root Cause Analysis
In `src/vehicle_testing/controller.py`, the boundary comparison logic used a non-strict inequality `>=` instead of a strict inequality `>`:

```python
# Defective code:
if (
    speed_kmh >= self.config.max_speed_kmh
    or temperature_c > self.config.max_temperature_c
):
    return ControllerState.WARNING
```

Because `speed_kmh == 130.0` satisfies `speed_kmh >= 130.0`, the evaluation prematurely branched into `WARNING`.

---

## 8. Code Fix
The condition was corrected to enforce strict inequality `>` as specified:

```python
# Corrected code:
if (
    speed_kmh > self.config.max_speed_kmh
    or temperature_c > self.config.max_temperature_c
):
    return ControllerState.WARNING
```
